# 实验记录模板

> **使用方式**：复制本文件为 `experiments/YYYYMMDD_<实验名>.md`（如 `experiments/20250115_baseline.md`），
> 填写后随代码一起提交。**状态**：`计划中` / `进行中` / `已完成` / `已归档`

## 元信息

| 项目 | 内容 |
|---|---|
| 实验编号 | EXP-001 |
| 日期 | 2025-01-01 |
| 负责人 | 张三 |
| 关联 Issue | #123（可选） |
| 配置文件 | `configs/config.yaml`（或 `experiments/xxx_config.yaml`） |
| 代码版本 | `git rev-parse HEAD` 的输出 |
| 环境 | conda 环境名 / Python 版本 |

## 1. 实验目的

（为什么做这个实验？要验证什么假设？解决什么问题？）

## 2. 数据集

（数据集名称、来源、规模、划分方式、预处理说明。更新 `data/README.md` 数据字典）

## 3. 参数设置

（模型结构、超参数、随机种子、训练配置——与配置文件逐项对应，说明关键参数的**选择理由**）

## 4. 方法

（方法描述、对比基线、评估指标及其定义、消融设置）

## 5. 结果

（指标表格、图表路径——图表输出到 `experiments/results/`，与基线的对比）

## 6. 分析

（结果说明了什么？为什么好/不好？有无异常或反直觉现象？可能的偏差来源？）

## 7. 下一步计划

（改进方向、待验证的新假设、关联的新实验）
