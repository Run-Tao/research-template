# 数据说明（Data Dictionary）

本目录管理项目数据，遵循 **raw → processed** 单向流水线，保证每一步可追溯、可复现。

## 目录结构

| 目录 | 用途 | 是否入 Git |
|---|---|---|
| `raw/` | 原始数据，**只读不改** | ❌ 不入库（大文件/不可复现），真实数据放本地或网盘 |
| `processed/` | 清洗/特征工程后的数据，由脚本生成 | ✅ 小文件可入库，大文件请用网盘或 Git LFS |

## 处理流程

1. 原始数据放入 `raw/`（不入 Git）
2. 运行 `python -m src.data.make_dataset` 生成 `processed/` 数据
3. 所有代码/实验只读取 `processed/` 数据

## 注意事项

- 大文件（>50MB）不要直接提交 Git
- 处理脚本必须可复现，处理过程记录在对应实验记录中
- 修改数据前先备份原始数据（raw 只读原则）
