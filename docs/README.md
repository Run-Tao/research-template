# docs/ — 团队知识库

本目录存放"过程性"知识：设计方案、会议纪要、文献笔记。
与 `paper/`（正式论文）和 `experiments/`（实验记录）互补。

| 子目录 | 用途 | 命名约定 |
|---|---|---|
| `design/` | 技术方案、架构设计文档 | `YYYYMMDD_主题.md` |
| `meetings/` | 组会/会议纪要 | `YYYYMMDD_议题.md` |
| `literature/` | 文献笔记（每篇论文一页） | `作者_年份_简短标题.md` |

## 文献笔记模板（literature/ 下每篇论文一个文件）

```markdown
# <论文标题>

- 作者 / 年份 / 发表渠道 / DOI
- **问题**：解决什么问题？
- **方法**：核心思想与创新点
- **结果**：关键指标与结论
- **启发**：对我的项目有什么可借鉴的？
- **复现链接**：官方代码地址（如有）
```

> 为什么：`.bib` 只保存引用格式，这里保存"你对文献的理解"。
> 写论文时两者配合，避免"引了但说不清它做了什么"。
